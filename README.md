# Café Doke

A modern, visually rich landing page for Café Doke — a welcoming café experience rooted in peace, flavor, and community.

This project showcases a polished one-page website designed to introduce the café, highlight its menu, reflect its ambiance, and make it easy for visitors to find the location and get in touch.

## Overview

Café Doke is being presented as more than just a café — it is positioned as a cultural experience that blends:

- warm hospitality
- specialty coffee and comfort food
- Nepali-inspired ambiance
- a community-centered atmosphere

The website delivers this identity through a refined design, smooth scrolling, elegant sections, and responsive layouts that work across desktop and mobile devices.

## What This Project Delivers

This project includes:

- a strong hero section with a branded introduction
- a grand opening announcement banner
- a story section describing the café’s concept and values
- a detailed menu section with multiple categories
- a vibe/gallery section showcasing the atmosphere
- a contact section with location and visit details
- a modern, polished visual style tailored to the brand

## Features

- Responsive single-page website
- Clean and elegant UI design
- Smooth navigation and scroll interactions
- Custom typography and warm earthy color palette
- Sections for story, menu, ambiance, and contact
- No build tools required — simple static website

## Tech Stack

- HTML5
- CSS3
- Google Fonts
- SVG and image-based visual elements

## How to Run

Open the project directly in your browser:

1. Open the project folder
2. Double-click on index.html
3. The website will load locally in your browser

You can also use a local development server if preferred, but this project is fully static and does not require installation.
